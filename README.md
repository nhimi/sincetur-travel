# Sincetur Travel 🌎

**App de Informações Turísticas** — descubra destinos, atrações e dicas de viagem.

## Sobre o Projeto

O **Sincetur Travel** é uma aplicação web voltada para turistas e viajantes que desejam explorar destinos turísticos, conhecer atrações locais, encontrar hotéis e restaurantes, além de obter informações práticas sobre cada localidade.

## Funcionalidades

- 📍 **Destinos** – listagem e busca de destinos turísticos
- 🏛️ **Atrações** – pontos turísticos com descrição, fotos e avaliações
- 🏨 **Hospedagem** – hotéis e pousadas recomendados
- 🍽️ **Gastronomia** – restaurantes e culinária local
- 🗺️ **Mapa interativo** – localização de atrações e serviços
- ⭐ **Favoritos** – salve os destinos que deseja visitar

## Tecnologias Utilizadas

- **HTML5** – estrutura semântica
- **CSS3** – estilização responsiva com variáveis CSS e Flexbox/Grid
- **JavaScript (ES6+)** – lógica e interatividade

## Como Executar

```bash
# Clone o repositório
git clone https://github.com/nhimi/sincetur-travel.git

# Entre na pasta do projeto
cd sincetur-travel

# Abra o arquivo principal no navegador
open index.html
```

> Nenhuma instalação adicional necessária — a aplicação roda diretamente no navegador.
